# システム概要 — 製造業向け外観検査画像解析システム

## 概要

本システムは、製造ラインで撮影された製品画像に対し、AI（深層学習モデル）を用いて外観不良を自動判定するプロトタイプです。  
Windows デスクトップ HMI（Human Machine Interface）から操作し、推論結果をリアルタイムで表示・記録します。

---

## システム構成

```
┌─────────────────────────────────────────────────────────┐
│  WinForms HMI (.NET 10 / win-x64)                        │
│  　↑ユーザー操作・結果表示・履歴管理                    │
│                        │                                  │
│           ┌────────────┴────────────┐                    │
│           ▼ ONNXモード              ▼ APIモード           │
│    ONNX Runtime (C#)          FastAPI (Python)            │
│    mobilenetv2.onnx           uvicorn / ONNX Runtime      │
│    C#内で直接推論             HTTP経由で推論              │
└─────────────────────────────────────────────────────────┘
```

| レイヤー | 技術 | 役割 |
|----------|------|------|
| HMI (フロントエンド) | C# / WinForms / .NET 10 | 操作UI・結果表示・CSV記録 |
| 推論エンジン A | ONNX Runtime for C# 1.20.1 | インプロセス推論（低遅延） |
| 推論エンジン B | FastAPI + ONNX Runtime Python 1.18.0 | マイクロサービス推論 |
| AI モデル | MobileNetV2 (ImageNet 1000クラス) | 画像分類 |
| ログ | CSV ファイル | 検査履歴の永続化 |

---

## 主な機能

### 1. 画像入力
- ファイル選択ダイアログから JPEG / PNG を読み込み
- Webカメラキャプチャ（設定から切り替え可能）

### 2. AI 推論
- **ONNX モード**: C# プロセス内で直接実行。外部プロセス不要・低遅延
- **API モード**: Python FastAPI サーバーへ HTTP POST。モデル差し替えが容易

### 3. 結果表示
- 判定バナー（OK 緑 / NG 赤）
- 確信度（%）・推論クラス・推論時間（ms）
- Top5 推論候補グリッド（クラス名・確信度）

### 4. 検査履歴
- 直近の検査をグリッドで一覧表示
- 統計パネル（総検査数・NG 数・OK 率）

### 5. CSV ログ
- 検査ごとに自動保存（`Logs/inspection_log_YYYYMMDD.csv`）
- 記録項目: 検査日時、ファイル名、パス、判定、スコア、クラス、メッセージ、通信結果、推論時間

---

## 判定ロジック

| 条件 | 判定 |
|------|------|
| 最高確信度クラスのスコア ≥ 閾値（デフォルト 70%） | **OK** |
| 最高確信度クラスのスコア < 閾値 | **NG** |

閾値は設定ダイアログから変更可能。

## 想定ユースケース

1. **ラインサイドでのリアルタイム検査**  
   作業員がカメラ前に製品をかざし、判定結果を即座に確認。

2. **オフライン画像の一括確認**  
   検査済み画像ファイルを読み込み、後工程で再評価。

3. **モデル評価・切り替え**  
   ONNX 形式のモデルを差し替えるだけで別モデルに切り替え可能。
