# テスト仕様書 — 外観検査画像解析システム

## 8.1 FastAPIテスト

| No | テスト項目         | 操作                        | 期待結果                        |
|----|-----------------|-----------------------------|---------------------------------|
| 1  | API起動確認       | uvicorn app.main:app --reload | 正常起動する                    |
| 2  | health確認       | GET /health                 | `{"status":"ok","message":"..."}` |
| 3  | 正常画像送信      | POST /inspect (jpg)          | result / score / defect_type が返る |
| 4  | 画像なし送信      | POST /inspect fileなし        | 422 Unprocessable Entity        |
| 5  | 非画像送信        | POST /inspect (.txt)         | 400 非対応形式エラー            |
| 6  | モデルなし        | models/配下にonnxなしで起動   | ダミー判定にフォールバックし起動する |
| 7  | 壊れた画像送信    | 破損ファイルを送信            | 400 デコード失敗エラー          |

### FastAPIテスト実行手順

```bash
# Swagger UIで手動テスト
http://localhost:8000/docs

# curl でヘルスチェック
curl http://localhost:8000/health

# curl で画像送信
curl -X POST http://localhost:8000/inspect \
  -F "file=@backend/sample_images/test.jpg"
```
