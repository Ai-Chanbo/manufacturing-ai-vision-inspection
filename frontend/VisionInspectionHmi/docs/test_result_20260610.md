## テスト方法

1. アプリをリリースビルドで起動（`VisionInspectionHmi.exe`）
2. 設定ダイアログで推論モードを「ONNX」に設定
3. テスト用画像 `backend/test_images/cat.jpg` を選択
4. 「検査開始」を押下し、各表示項目を目視確認
5. CSV ファイルの内容を確認
